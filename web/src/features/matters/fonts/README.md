# Bundled practitioner fonts

Latin WOFF2 files from `@fontsource/public-sans@5.3.0` and
`@fontsource/newsreader@5.3.0`, distributed under the accompanying SIL Open Font
Licenses. Only the weights currently used by the practitioner shell are bundled:
Public Sans 400/600 and Newsreader 500. No runtime font service is used.
