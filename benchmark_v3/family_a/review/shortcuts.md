# Which rules recover the changing trustee?

Each cell reports the name the rule would select for the Second Seat. A name can coincide with the reference while providing insufficient evidence for the edge.

| Rule | A0 completed | A1 reordered | A2 deferred |
| --- | --- | --- | --- |
| Document-based reference | Tamsin | Tamsin | Darren |
| Latest dated document, forced to pick its named candidate | Darren | Darren | Darren |
| Last presented document, promoting a named replacement or falling back to a named candidate | Darren | Tamsin | Darren |
| Keep every asserted or proposed holder | Both | Both | Both |
| Promote the pencilled bank slip | Tamsin | Tamsin | Tamsin |
| First changing candidate named | Darren | Darren | Darren |
| Most frequent changing candidate | Darren | Darren | Darren |
| Titles and identifiers only | Undetermined | Undetermined | Undetermined |

The latest dated document is Iona’s family archive message. Reading it literally supplies no current Second Seat determination. Reading only the last presented Source also supplies none in all three conditions. The last-source fallback above happens to select the right person in A1 and A2. Merging the two Brell names corrupts the unchanged First Seat and the sibling edge. Exact full names occur ten times for Darren and four for Tamsin. Counting whole first-name tokens instead gives eleven and five.

These controls test specified reading rules on one three-condition family. They establish neither model behaviour nor resistance to every heuristic. For example, someone who already knew the two candidates could map the words RELEASED and HOLD to the right names across all three bundles without supplying evidence linking the instrument.
