## Batch handoff

Return one JSON object conforming to the supplied schema. List the natural
Source inventory in dated order. Use opaque stable Source IDs and provide each
record's origin and transmission in its provenance. Prior received IDs must
refer to earlier records. Keep the private history separate from the neutral
meeting brief and each participant's factual brief. Include the exact baseline
literal in the affected participant's brief where an edit requires one. Give
authors ordinary documentary instructions without explaining the experiment.

Use the family ID followed by a three-digit zero-based index in the private
target declarations. The natural condition has index 000. List matched
conditions in index order. Commit one literal body edit or a pure permutation
for each sibling. Declare the planned critical candidate edges and required
subset for each condition. Separate these limited declarations from the full
graph, which is decided from documents by independent readers.

For a sectioned Matter, partition the natural inventory into sections and
propose optional increasing Source-count snapshots. Each blind reader will
reconcile their own sections against the full file independently.
